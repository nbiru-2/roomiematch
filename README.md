# RoomieMatch

**Find a roommate you can actually live with.**

## Project Overview

RoomieMatch is a web application designed to help people evaluate roommate compatibility before spending time on lengthy conversations, introductory calls, and apartment viewings.

The platform will allow people offering rooms in shared apartments to create a household profile, define their living preferences, and share a questionnaire with potential roommates.

Applicants can answer the questionnaire, allowing both parties to identify shared preferences, differences, and topics worth discussing.

## The Problem

Finding a roommate involves more than finding someone who can afford the rent. Differences in cleanliness, daily routines, social habits, smoking preferences, guests, and communication expectations can make shared living difficult.

These differences are often discovered only after exchanging multiple messages or attending introductory meetings.

RoomieMatch aims to make this process more efficient and transparent.
